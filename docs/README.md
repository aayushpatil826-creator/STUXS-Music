# STUXS Music - GitHub Pages In-App Update Distribution

This directory serves the self-hosted STUXS In-App Update manifest via GitHub Pages.

## 1. Setup GitHub Pages
- In repository Settings -> Pages, select branch main (or master) and folder /docs.
- Manifest URL: https://aayushpatil826-creator.github.io/STUXS-Music/update.json

## 2. Release Asset URL
- APK URL: https://github.com/aayushpatil826-creator/STUXS-Music/releases/download/<RELEASE_TAG>/<APK_FILENAME>
